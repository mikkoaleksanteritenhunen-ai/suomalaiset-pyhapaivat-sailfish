Suomalaiset Pyhäpäivät

Suomalaiset Pyhäpäivät is an offline Sailfish OS application for viewing Finnish public holidays, flag days, election days, and other notable calendar events.

The application provides a Finnish-style calendar experience with support for holiday information, flag day information, reminders, multilingual user interfaces, and calendar exports.

Features

Calendar
-Monthly calendar view
-ISO week numbers
-Monday-first Finnish calendar layout
-Support for years 2020-2100
-Enhanced holiday and flag day highlighting
-Customizable calendar appearance

Finnish Public Holidays
-Complete list of Finnish public holidays
-Support for movable holidays such as Easter
-Holiday descriptions and explanations
-Next upcoming holiday calculations
-Holiday detail pages

Finnish Flag Days
-Official Finnish flag days
-Established flag days
-Election day flagging information
-Next upcoming flag day calculations
-Detailed flag day information pages

Election Days
-Future Finnish election dates
-Election day flagging information
-Election descriptions and background information

Search
-Search holidays and flag days
-Quick access to detailed information pages

Notifications
-Background reminders for upcoming holidays
-Background reminders for upcoming flag days
-Configurable reminder timing
-Fully offline notification scheduling

Calendar Export (v0.5 and later)
-Export Finnish public holidays to iCalendar (.ics)
-Export Finnish flag days to iCalendar (.ics)
-Export both event types into a single calendar file
-Select export year
-Automatic file naming
-Saved directly to the Downloads folder
-Open exported files in compatible calendar applications

Multilingual Interface

Privacy

Suomalaiset Pyhäpäivät is designed with privacy in mind.
-No user tracking
-No analytics
-No cloud services
-No user accounts
-No personal data collection
-Fully functional without internet access

All calculations are performed locally on the device.

Technical Information
-Platform: Sailfish OS
-Framework: Qt / QML / C++
-Works fully offline
-Uses local calculations for holidays and flag days
-Supports iCalendar (ICS) export
